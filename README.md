# Bakushkina Olga — портфолио бренд-дизайнера

Веб-приложение портфолио с упором на визуальные эффекты (2026), собранное по реальному макету
Figma и контенту заказчика: кинематографичный тёмный дизайн, крупная типографика, GSAP-параллакс
и Framer Motion анимации на каждом взаимодействии. Внутри — приватный калькулятор стоимости услуг.

Референсы стиля: [lusion.co](https://lusion.co) + [eszterbial.com](https://eszterbial.com).
Контент, тексты, реальные проекты и ассеты — из авторского Figma-макета (см. `upload/`).

## Стек

- **React 19** + **Vite 6** + **TypeScript** (strict mode)
- **Tailwind CSS v4** — CSS-переменные для dual-theming (тёмная/светлая тема)
- **Framer Motion 11** — все анимации компонентов, spring-физика
- **GSAP** (ScrollTrigger) — параллакс hero-секции, появление карточек портфолио и таймлайна при скролле
- **Zustand** — глобальный стейт: тема, активный экран, points balance
- **React Router v6** — маршрутизация
- **Lucide React** — иконки

## Структура сайта

- `/` — главная: hero с 4 карточками ключевых проектов, «Мой путь» (карьерный таймлайн),
  бегущая строка направлений, избранные работы, направления работы, статистика, CTA
- `/portfolio` — сетка всех проектов с фильтром по категории (маскоты / соцсети / брендинг / презентации)
- `/portfolio/:id` — детальная страница проекта: задача, роль, галерея, результат (там где есть NDA — отмечено)
- `/about` — об Ольге, направления, полный карьерный путь, процесс работы
- `/contact` — телефон, Telegram, email + форма (mailto)
- `/calculator` — **внутренняя** страница расчёта стоимости услуг (RU/US/EU, срочность, права
  на использование, история расчётов). Ссылка на неё спрятана мелкой точкой в футере сайта.

1. **Маскоты для «Альфа Страхование — Жизнь»** — персонажи и AI-анимация для корпоративного обучения
2. **Коммуникационный дизайн «Домашний»** — маскот-птица и соцсети для телеканала

## Разработка

```bash
npm install
npm run dev
```

## Продакшн-сборка

```bash
npm run build
npm run preview
```

## Деплой на Vercel

- `vercel.json` — SPA fallback rewrites
- `.npmrc` — `legacy-peer-deps=true`

Подключите репозиторий к Vercel — фреймворк (Vite) определится автоматически.
