# Ольга Бакушкина — портфолио дизайнера

Веб-приложение портфолио с упором на визуальные эффекты (2026): кинематографичный тёмный дизайн,
крупная дерзкая типографика, GSAP-параллакс и Framer Motion анимации на каждом взаимодействии.
Внутри — приватный калькулятор стоимости услуг (не для клиентов, только для Ольги).

Референсы стиля: [lusion.co](https://lusion.co) (тёмная кинематографичная база, 3D-визуал) +
[eszterbial.com](https://eszterbial.com) (дерзкая крупная типографика).

## Стек

- **React 19** + **Vite 6** + **TypeScript** (strict mode)
- **Tailwind CSS v4** — CSS-переменные для dual-theming (тёмная/светлая тема)
- **Framer Motion 11** — все анимации компонентов, spring-физика
- **GSAP** (ScrollTrigger) — параллакс hero-секции, появление карточек портфолио при скролле
- **Zustand** — глобальный стейт: тема, активный экран, points balance
- **React Router v6** — маршрутизация
- **Lucide React** — иконки

## Структура сайта

- `/` — главная (hero, marquee услуг, избранные работы, направления, статистика, CTA)
- `/portfolio` — сетка всех проектов с фильтром по категории
- `/portfolio/:id` — детальная страница проекта
- `/about` — об Ольге, направления, процесс работы
- `/contact` — контакты и форма (mailto)
- `/calculator` — **внутренняя** страница расчёта стоимости услуг (RU/US/EU, срочность, права
  на использование, история расчётов). Ссылка на неё спрятана мелкой точкой в футере сайта —
  в основной навигации её нет.

## Особенности

- Кастомный курсор-компаньон на десктопе
- Курсы ЦБ РФ с кешем на сутки и резервным значением при недоступности API
- История расчётов калькулятора в localStorage
- PWA install-prompt на мобильных через `beforeinstallprompt`

## Разработка

```bash
npm install
npm run dev
```

## Продакшн-сборка

```bash
npm run build
npm run preview
```

## Деплой на Vercel

- `vercel.json` — SPA fallback rewrites
- `.npmrc` — `legacy-peer-deps=true`

Подключите репозиторий к Vercel — фреймворк (Vite) определится автоматически.
